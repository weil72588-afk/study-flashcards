导入闪卡

支持 #CARD 格式或 JSON。
支持两种图片导入：① JSON 内直接包含图片数据；② 同时选择 JSON + 图片文件，并在 JSON 里填写图片文件名。

闪卡文件会合并到当前卡库；完整备份会覆盖当前数据。图片会压缩后保存到当前 iPhone 的 IndexedDB，不占 GitHub 仓库空间。

请把我接下来发给你的错题整理成适合长期复习的闪卡。不要机械抄题，每道题只保留最值得迁移的 1～2 张；没有复习价值的题可以不做卡。 如果只需要文字卡，请严格输出下面格式，不要加 Markdown 代码框： #CARD 卡组: 言语错题 正面: 用一个能触发回忆的问题/提示来写 背面: 用最短但足够准确的答案，必要时包含“错因/下次动作” 标签: 标签1, 标签2 来源: 本次错题 备注: 可选 #END 如果我明确说“做成图片导入文件”，请生成一个可下载的 JSON 文件。每张卡支持字段：deck/front/back/tags/source/note/frontImage/backImage；frontImage 和 backImage 可以直接包含 data:image/... 图片数据。这样我在“文件导入”里选择该 JSON，就能把文字和图片一起导入。
